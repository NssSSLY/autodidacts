确认操作


第一次使用
演示界面无需数据库。真实工作台需要 Python 3.12+、PostgreSQL + pgvector，以及你选择的模型配置。
  1. 先查看项目 doc/02部署指南.md，准备 .venv 和 .env。
  2. 按部署指南备份并显式初始化数据库；页面不会自动迁移。
  3. 运行下面命令打开真实工作台，创建目标后手动开始学习。
.\.venv\Scripts\python.exe -m autodidact.cli serve --port 8765
浏览器访问 http://127.0.0.1:8765。演示启动命令：
.\.venv\Scripts\python.exe -m autodidact.ui_preview --port 8766
问答可能调用模型与嵌入服务；学习计划可能调用搜索和模型。证据不足保持未知，模型解释不会直接写为信念。
