# Autodidact：持久自学习研究智能体

Autodidact 面向限定领域的长期研究：自主维护目标、检索独立资料、提出主张、核查证据、处理争议、评估掌握程度并积累研究方法。LLM 是可替换的认知工具，不是智能体身份；模型输出不是事实。

当前版本是 **主要链路已接通、仍待实环境与长期实验验收的 V0.1 原型**。不能将能力数量或旧测试结果解释为“已经证明自动变聪明”。

## 当前已经接通什么

- 目标池与持久学习循环：规划、搜索、阅读、Claim、Belief、Evidence、Dispute 与历史。
- 原文锚点和语义支持判断、来源质量与传递血缘去重、冲突晋升禁入、四结果争议调查。
- F01-A 主张条件/时间/单位提议、范围覆盖核验与逐引文审计，show-claim 可查看原文及理由；未知范围不等于普遍适用。
- F01-B/C/D 来源作者/发布日期/DOI、arXiv、PMID 声明与出处，复合父句/原子子句分别核验，正文质量锚点/等级上限；show-source、show-claim 可审计。
- F02 原结论/原范围反对与条件引文关联、历史信念独立再核查、过旧/质量下降复核目标；show-belief、queue-belief-reviews 可操作和审计。
- F05 认知只读审计与受控人工复核：冻结原依据、逐项摘要确认、复核/争议调查排队或来源校正批注、幂等操作记录；不直接修改真值/证据等级或启动模型。
- F03 可靠真值与版本化评估：可复算算术/人工核查声明、冻结版本与完整 hash、训练题直接重合拒绝、独立评分、延时保持复测、离线重评分；不同协议/模型分组，不混算历史分数。
- F06 来源与提供方运营可靠性：搜索、阅读、API 模型、嵌入及网页模型的有界重试/熔断、脱敏健康快照、逐次预算与失败分类；网页模型不自动重发。
- F07 持久候选索引、工作项进度、有界后台重建、暂停/续跑/失败重试、完整性校验与原子启用；旧向量和认知保留。
- F04 高置信旧信念迁移盲审：冻结人工中性问题和旧认知，独立盲答先入库，再重读旧源/独立核源；合格证据才排争议，不自动采用新模型答案。
- F09 主题掌握与缺口：重算既有可靠答卷、按固定模型/记忆分组，汇总覆盖/迁移/真实延时保持/校准及当前证据，提供只读画像、快照和无题面学习目标；未知不当掌握。
- F10 概念与九类方向关系、原主张/原范围和逐引文复核、动态状态/不可变历史、只读网页及前置调查目标；模型提议不当事实，共现不当因果。
- F13 信念/技能维护：重复/相似/过旧建议、逐项确认、非破坏性归并、归档/恢复及不可变操作历史；归档不是判假，不转移证据。
- F11 显式认知来源清单、分阶段独立盲答→批判→综合、0级论证图和来源追踪、可回退路由建议；不投票判真、不自动换模型或改旧信念。
- F12 方法适用条件/局限/训练出处、失败反例、固定模型/记忆的重复A/B、显式启用/回退和规划门控；研究方法是参考，不执行代码或自主改核心逻辑。
- F14 只读实验与长期观察界面：UTC真实记录跨度/资源结算与预留/错误、报告目录、精确条件组历史、可靠逐题/四组迁移/真实保持复算及F11/F12审计；不模拟30天或自动收费答题。
- PostgreSQL/Alembic 0001–0011（仍22个业务表）、数据库唯一约束、控制器锁、预算与工作项续跑。
- Goal/Claim/Belief 关键词 + pgvector 混合召回，嵌入失败降级和分批维护。
- 隔离闭卷/独立核源、观察/Profile、冻结基准、四组模型比较、记忆/候选技能/30 天报告机制。
- 本地浏览器研究工作台、文档导入、可选网页模型；F08 有限运行计划、只读就绪/存活、进度与轮转日志、一致快照备份/仅新空库恢复、版本化 EXE 文件夹发布清单。

## Windows 最短启动路径

需要 Python 3.12+ 和带 pgvector 的 PostgreSQL。Docker 仅用于数据库，不要求服务器。先按部署指南检查 Compose 演示密码及端口：当前为 `5432:5432`，共享网络部署应改回环绑定并换强密码。

在项目根目录 PowerShell 执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
if (-not (Test-Path -LiteralPath '.env')) {
    Copy-Item -LiteralPath '.env.example' -Destination '.env'
}
# 编辑 .env：数据库、真实模型和可选搜索/嵌入配置
notepad .env
docker compose up -d postgres
.\.venv\Scripts\python.exe -m autodidact.cli init-db
.\.venv\Scripts\python.exe -m autodidact.cli bootstrap
.\.venv\Scripts\python.exe -m autodidact.cli serve --port 8765
```

浏览器访问 http://127.0.0.1:8765。不用网页也可执行 `run-once`、`run --max-cycles 5`、`status`。默认 mock 只演示程序路径，不证明真实研究可用。`pytest` 仅需开发时安装 `.[dev]`；普通工作台不需要 Playwright 浏览器二进制。

EXE 配方、服务器运行、原生数据库、备份恢复和完整命令见部署/使用指南，不要将示例当作生产安全配置。
