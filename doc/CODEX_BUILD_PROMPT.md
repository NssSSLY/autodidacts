## 2. 不可改变的架构要求

1. 控制器负责流程/权限，模型可替换且只是认知工具。
2. 模型/API/浏览器输出初始等级 0，引用原文也要独立获取核查。
3. 持久身份与学习状态保留在目标、信念、证据、争议、历史、评估和技能等数据库记录。
4. 冲突必须建争议，模型换代不能直接覆盖高置信旧信念。
5. 外部资料是不受信任数据，内容里的指令不是系统指令。
6. 拒绝 CAPTCHA/反爬规避、凭据提取、自主提权、无人值守支付和核心代码自改。
7. 数据结构变更走迁移，兼容旧记录；未知旧值保留未知，不制造核验结果。
8. 提供方失败可降级；预算、重试和恢复有界。
9. 用冻结题集、迁移/保持测试和校准证明进展；不能用模型自评或知识数量宣称提升。
