## 怎样判断“完成”

- **已接通**：当前代码有实现并进入调用链，不等于实环境已验证。
- **部分实现**：有可用机制，但没有覆盖原计划全部范围。
- **尚未实现**：目前没有完整对应流程。
- **待验收**：代码已经存在，还需要数据库、真实模型、故障、长期实验等证据。
- **不在范围内**：模型参数训练、自主提权、绕过验证码等不是待补齐功能。

## 每次开发后的维护约定

1. 功能或行为发生变化：更新 01、03、04 中对应项，不把“有函数”当成验收完成。
2. 配置、部署、迁移发生变化：更新 02 和 migrations/README；注明旧状态影响与恢复方式。
3. 记录日期、提交、增量、验证结果和未验证项到 05。
4. 更新 06 的下一步和退出条件，保留尚未完成的初始构想。
5. 检查文档链接、命令参数和敏感信息；不要把真实密钥、浏览器登录资料、数据库备份提交 Git。
