## 本轮兼容与边界

迁移 `20261002_0004` 扩展操作事件、研究报告及技能元数据；`20261002_0005` 增加来源关系、会话工作项与统一检索索引，不删除旧认知行。向量指纹保存在已有信念 JSON 元数据；新条件决议使用关联调查会话的 Claim，保留原始输入主张。

本轮执行了代码编译、静态检查、CLI 帮助读取和 0005 迁移 SQL 离线生成，未运行 pytest、数据库迁移、真实模型请求、浏览器流程或 EXE 构建。
